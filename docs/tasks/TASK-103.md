# TASK-103 — Не учитывать picker line сверх остатка в multi-item sale

Статус: COMPLETED

## Цель

Не позволять повторно выбранному variant попасть в sale draft, если все его единицы уже зарезервированы строками Current sale.

## Предполагаемые файлы

- `features/sales/ui/sale-flow.tsx`
- `features/sales/ui/sale-flow.test.tsx`
- `docs/PROJECT_STATUS.md`

## Зависимости

TASK-102.

## Критерии готовности

- При остатке 1 повторный выбор variant не увеличивает счётчик.
- Пользователь видит понятное сообщение, что свободных единиц больше нет.
- Подтверждение отправляет только доступные строки.

## Тесты

- Component test: stock 1, повторная заполненная строка не учитывается.
- `npm run test`, `npx tsc --noEmit`, `npm run build`.

## Результат

- Filled picker line учитывается только при наличии свободной единицы после резервирования Current sale.
- Для полностью зарезервированного size показывается локализованное сообщение вместо ложного увеличения счётчика.
