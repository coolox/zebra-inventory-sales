Статус: COMPLETED

## Цель

Сделать количество на кнопке и состав отправляемой корзины полностью явными, без автоматического повторного добавления выбранной позиции.

## Предполагаемые файлы

- `features/sales/ui/sale-flow.tsx`

## Зависимости

Нет.

## Критерии готовности

- Кнопка Sell отправляет ровно строки, показанные в Current sale.
- Незавершённый picker не увеличивает quantity автоматически.
- Пустую корзину нельзя отправить.

## Тесты

- Component test: две строки в корзине дают Sell 2 items и две draft lines.
- Component test: выбранная, но не добавленная позиция не отправляется.
- Mobile keyboard/touch smoke-test.

## Результат

- Отправка использует только строки корзины; незавершённый выбор в picker больше не меняет sale draft.
- Component-тест покрывает две строки, незавершённый picker и пустую корзину.
